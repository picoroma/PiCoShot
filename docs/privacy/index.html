Informativa sulla privacy

Ultimo aggiornamento: 21 ottobre 2026
Sviluppatore: PiCoDev
Contatto: picodev@cocco.biz

In sintesi. PiCoShot non raccoglie, non trasmette e non condivide alcun dato personale. L'app non si connette a internet, non ha account, non contiene pubblicità né strumenti di telemetria o analisi.

Cosa fa l'app con i tuoi dati

  • Contenuto dello schermo. Quando premi la scorciatoia di cattura, PiCoShot acquisisce un'immagine dello schermo e la tiene solo in memoria finché l'anteprima è aperta. Non viene inviata a nessuno. Viene scritta su disco solo se tu scegli di salvarla.
  • Appunti. L'app scrive negli appunti (immagine e/o testo) solo quando lo chiedi tu (copia, OCR, pulsante OK). Non legge il contenuto degli appunti.
  • Riconoscimento del testo (OCR). Viene eseguito sul tuo dispositivo con il motore OCR integrato in Windows. Nessun testo o immagine esce dal computer. Se attivi l'azione «OCR su file», il testo riconosciuto viene accodato a un file di testo (PiCoShot_OCR.txt) nella cartella degli screenshot scelta da te.
  • File creati sul tuo dispositivo. Immagini salvate (PNG, JPG o BMP) nella cartella che scegli; il file di testo OCR (solo se attivato); un file di impostazioni (PiCoShot.ini: scorciatoie, cartella, lingua OCR, colore, azioni predefinite); un file di registro degli errori (PiCoShot.log) che contiene solo messaggi tecnici di errore. Questi file restano sul tuo dispositivo e puoi cancellarli quando vuoi.
  • Stampa. Se scegli di stampare, l'immagine viene inviata alla stampante che selezioni, con le regole di quella stampante (anche di rete).
  • Avvio con Windows. È disattivato di default e si attiva solo se lo scegli.

Condivisione con terzi

Nessuna. PiCoShot non trasmette dati allo sviluppatore, a servizi cloud o ad altre parti.

Sicurezza e conservazione

I dati non lasciano il tuo dispositivo. Le immagini e i testi salvati restano dove li hai salvati finché non li elimini. Disinstallando l'app, i file che hai salvato nelle tue cartelle non vengono cancellati.

Minori

L'app non è rivolta ai minori e non raccoglie dati di alcuna persona, minori compresi.

Modifiche

Se in futuro l'app dovesse trattare dati in modo diverso (per esempio con funzioni online), questa informativa verrà aggiornata prima del rilascio di quelle funzioni.

Privacy Policy

Last updated: October 21, 2026
Developer: PiCoDev
Contact: picodev@cocco.biz

Summary. PiCoShot does not collect, transmit or share any personal data. The app does not connect to the internet, has no accounts, no ads and no telemetry or analytics.

What the app does with your data

  • Screen content. When you press the capture shortcut, PiCoShot takes an image of your screen and keeps it in memory only while the selection overlay is open. It is never sent anywhere. It is written to disk only if you choose to save it.
  • Clipboard. The app writes to the clipboard (image and/or text) only when you ask for it (copy, OCR, OK button). It does not read the clipboard.
  • Text recognition (OCR). Runs on your device using the OCR engine built into Windows. No text or image leaves your computer. If you enable the “OCR to file” action, recognized text is appended to a text file (PiCoShot_OCR.txt) in the screenshots folder you chose.
  • Files created on your device. Saved images (PNG, JPG or BMP) in the folder you choose; the OCR text file (only if enabled); a settings file (PiCoShot.ini: shortcuts, folder, OCR language, color, default actions); an error log (PiCoShot.log) containing technical error messages only. These files stay on your device and you can delete them at any time.
  • Printing. If you choose to print, the image is sent to the printer you select, under that printer's rules (including network printers).
  • Start with Windows. Off by default; enabled only if you choose.

Sharing with third parties

None. PiCoShot does not transmit data to the developer, cloud services or any other party.

Security and retention

Data never leaves your device. Saved images and texts stay where you saved them until you delete them. Uninstalling the app does not delete files you saved in your own folders.

Children

The app is not directed to children and collects no data from anyone, including children.

Changes

If the app ever handles data differently (for example with online features), this policy will be updated before those features are released.
